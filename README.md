# Sales Data Analysis Project

## Objective
Analyze a sample sales dataset to understand total revenue, product performance, monthly trends, and regional performance.

## Tools
- Python
- Pandas
- Matplotlib
- SQL (practice_queries.sql)

## Files
- `sales_data.csv`: sample dataset
- `sales_analysis.py`: complete Python solution
- `practice_queries.sql`: SQL practice queries
- `outputs/`: generated summary CSVs, charts, and insights after running the script

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Install packages: `pip install pandas matplotlib`
4. Run: `python sales_analysis.py`

## Questions answered
- What is total revenue?
- Which product earns the most revenue?
- Which month has the highest revenue?
- Which region generates the most revenue?
- How do product categories compare?

## Sample findings
Using the included sample dataset:
- Total revenue: ₹415,500
- Highest-revenue product: Laptop
- Highest-revenue month: March 2026
- Highest-revenue region: North

These results are from fictional practice data, not a real company's sales.
